# 操作说明

当前流程为 **上传 / 选页 → 整页图像识别与内容分类 → 分类 LaTeX → 独立复核与固定排版输出**。整页图像直接交给识别模型，程序统一应用固定样式；正文允许重新折行与自然分页，不需逐页人工批准或原行校准。

本轮固定排版改造 **未测试、未运行验证**。本文描述实现行为与用户入口；没有执行测试、构建、类型检查、lint、试编译、启动、模型请求或迁移。历史报告不能证明当前流程已验证。

## 启动与接入

Windows 双击根目录 `ocr.bat`，回车启动并打开页面。菜单可停止、重启及刷新状态；关闭菜单窗口后服务继续运行。命令行支持 `Start`、`Start -NoBrowser`、`Stop`、`Restart` 和 `Status`。后端监听 `127.0.0.1:8000`，前端监听 `127.0.0.1:5173`。环境和手动启动步骤见 [README](../README.md)。

数据默认在 `backend/data/`，可用 `EBOOK_OCR_DATA_DIR` 指定本地目录。启动器日志位于 `.cache/launcher/`。PDF 生成需要 XeLaTeX、Fandol 字体与模板宏包；启动器优先采用有效 `EBOOK_OCR_XELATEX`，再查 PATH 和常规 TinyTeX 目录，缺失时准备依赖。直接启动后端只查找编译器，不安装组件。缺少 XeLaTeX 会令 PDF 明确失败，已有内容及可生成的 JSON / LaTeX 单独保留。

模型设置保存后用于下次新任务；运行中的任务和恢复沿用冻结设置。

| 字段 | 用途 |
| --- | --- |
| API 协议 | `openai_responses` 或 Google Gemini 原生 `gemini`，显式选择 |
| API 根地址 | OpenAI 默认 `https://api.openai.com/v1`；Gemini 通常为 `https://generativelanguage.googleapis.com/v1beta` |
| Responses 路径 | OpenAI 使用，默认 `/responses`；留空直接请求根地址 |
| 模型列表路径 | 通常 `/models`；留空表示根地址为模型集合 |
| 页面代理模型 | 接收图像并支持结构化输出的识别、复核和恢复模型 |
| 推理程度 | 手动填写，留空使用服务默认 |
| 超时 | 单请求等待秒数 |
| 处理并发数 | 默认模型并发 `2`；生成 PDF 串行处理 |
| API 密钥 | 当前地址和协议的本地凭据 |

相对路径字段不要填完整 URL。Gemini 生成端点由模型集合追加 `/{模型名}:generateContent`，使用 API Key，不提供 Vertex OAuth。OpenAI 不自动回退 Chat Completions；接入协议、供应商与模型不会静默切换。

“获取模型”使用当前设置草稿读取模型列表，不发推理请求也不保存草稿；没有列表接口时可直接填模型 ID。“检查已保存配置”只检查本地模型和密钥存在性；两者都不代表真实图片或 Schema 能力。正常首页面请求确认实际能力，不另发付费预检。

OpenAI 推理参数作为 `reasoning.effort`；Gemini 的 `minimal/low/medium/high` 使用 `thinkingLevel`，不小于 -1 的整数使用 `thinkingBudget`。识别、复核和恢复各自使用独立上下文，OpenAI 为 `store:false`，Gemini 仅含当前请求的 `contents`。不累计跨页图像、答案或思考签名。结构化输出使用各协议自己的 Schema 参数，不发送额外输出 token 上限。

密钥明文保存在本机数据库，浏览器 `localStorage`、运行快照、书籍导出和日志不保存密钥。同地址同协议下留空保留已有凭据；切换接入需填写新密钥或明确清除。恢复任务若地址或协议已经改变，需先恢复原接入及相应凭据；新密钥不会被发到旧地址。HTTP 错误只显示状态码和限长、脱敏的供应商说明，配置错误停止无效调用。

## 上传、选页与开始识别

新建项目后添加一个或多个 PDF、PNG、JPEG，每文件上限 100 MB。PDF 保存原文件及轻量来源页记录，图像和预览按需准备；图片形成单页来源。部分导入失败时成功文件仍保留，界面逐项说明失败原因。上传及选页不调用模型。

选页默认全选，可按源文件或源页范围筛选并保存页序。选择草稿保存稳定的 `page_id` 和 `source_version`；取消选择不删除源文件、源页、修订或用量。永久页面编号 `number`、UUID `page_id` 与源文件页码 `source_page` 含义不同；界面所选页次从 1 开始，API 的 `position` 从 0 开始。

点击保存选择进入识别页。开始前可见固定规则；高级设置允许选择 A4、A5、A6、B5、B6 或 6×9 英寸纸型、请求额度和人工稿替换范围。所有纸型固定 25 mm 边距，正文 11 pt / 16.5 pt 行距、首行 2 字、段间 6 pt。标题、公式、表格、列表、图注、脚注等按 [固定规则表](FIXED_LAYOUT_WORKFLOW.md#固定规则版本-1) 排版。

点击“开始识别”后冻结选择、来源版本、模型、纸型、规则版本、策略及基准稿件。运行中保存新选择只影响下一次任务；正在处理时不能更改来源。字号、边距、原页画布和旧模板设置不参与新识别的固定排版。

已有人工稿默认保留。开始前明确允许替换的范围才可自动采用候选；旧修订继续归档。运行中新保存的人工稿也受到修订保护，本轮候选与输出单独保存，结果详情不会拿旧稿冒充新识别。

## 自动处理与暂停

技术阶段仍使用 `prepare → recognize → review → recover（按需）→ layout → render → export`：

1. 准备完整源页图像，首次识别直接发送整页，不先请求区域计划。
2. 按阅读顺序识别并分类输出 LaTeX 正文片段，先保存响应和有效内容。
3. 独立复核完整源页，从源页寻找遗漏并核对文字、公式、表格和分类；有明确理由和额度时整页重读恢复，再独立复核候选。
4. 程序套用固定模板，准备合格图形资源并生成 PDF 与其他输出。`layout` 在新流程表示固定规则和图资源准备，不表示原书版面恢复。

识别范围为印刷内容，手写批注、装饰和噪声排除。遮挡或无法确定内容保存为未决片段；不猜写文字，不把空数组当作完整识别或空白。整页图像为内容证据，输出不直接使用未核验源页或混合裁切回退。图形资源经独立核验，确认干净后才用于输出；无法安全形成时保留占位和明确原因，记录图形位置不代表已有图形资源。

正常页一次识别加一次独立复核。N 页默认共享物理请求额度 `6N`；每页安全上限 `12`，暂时错误重试最多 `2` 次、重读恢复安全上限默认 `2` 轮、候选编译最多 `3` 次。当前同一整页重读策略仅尝试一次；安全上限不代表一定执行对应轮数。请求在发送前预约，失败和结果未知的已发送请求也计数，额外处理优先保护其他页面的基础识别与首次复核。额度耗尽后保存可用内容和未决原因，用户可另行补做。

收到有界模型正文后先存本地再解析；已保存正文可本地重解析，不重新付费请求。截断不会猜补；保存失败明确记录“已收到但未保存”。普通界面和书籍输出不展示原始模型响应、密钥或请求资料。

暂停先停止新阶段与请求预约，已发送请求继续结算。状态先显示“正在暂停”，结算后显示“已暂停”。恢复使用同一 run ID、冻结设置及已完成阶段。服务中断后可恢复记录；消费未知的已发送请求不会静默重发。另有未结束任务时不能并发创建竞争任务。

内容结论与执行、输出状态分开：`usable / uncertain / unavailable / unverified` 表示内容可用、仍有未决、未取得内容或未完成复核。固定重排的布局通常为 `approximate`，界面显示“固定规则重排”，不表示原书版式准确。任务结束、编译成功或 PDF 可下载不能单独代表识别完整。

用量只累计供应商实际提供的 token；缺失为 `null`，不估算为零。`complete=false` 显示已知用量可能不完整，以供应商账单为准。

## 查看分类、原图和输出

逐页结果点击“分类与 LaTeX”，按顺序查看标题、正文、公式、表格、列表、图注、脚注、代码等类别及其源码片段。图形单独显示说明，未决片段和内容问题分别列出。页面类型仍在 `PageContent.page_kind` 中保存并在内容面板显示，封面和目录使用相同的分类 LaTeX 路径。

“查看原页”或内容面板的“对照原图”读取本轮冻结来源。原图供内容核对，固定重排允许源页与输出页数不同。快照 PDF 可直接展开预览；完整模板和引用资源在 LaTeX 包中提供。

任务结束后后台自动冻结输出快照，各格式状态为 `pending / generating / available / failed`，可用格式立即可下载：

| 格式 | 内容 |
| --- | --- |
| JSON | 同一快照页序、来源、修订、分类内容、未决说明与结果结论 |
| PDF | 逐源页按固定模板折行、自然分页，再按选择顺序合并；单张源页可形成多个输出页 |
| LaTeX / ZIP | 固定模板、分类源码、JSON 及全部引用图形资源 |

输出不是原书视觉复刻。格式生成失败时显示原因与完整缺失页列表，其他可用格式不受影响。下载只读冻结资产，不额外识别、复核或编译。更改当前选择、纸型或人工稿不改写历史快照；“继续处理未完成项”按原运行冻结范围、纸型和输出设置补做，“按当前选页开始新识别”进入当前默认固定流程。

## 人工编辑与历史边界

“更多”中的人工编辑是可选工具，不是识别必经步骤。当前固定生成稿使用完整 LaTeX，实际修改后保存为人工源码；原识别内容和快照保留。页面的 `recognition_scope` 和 `fixed_layout_version` 记录来源，`manual_protected` 表示人工稿，不能因此声称人工修改仍满足自动固定规则。

人工稿保存提交 `expected_content_revision` 与 `expected_layout_revision`；冲突返回 409，读取最新修订后再保存。试编译预览与当前稿 PDF 属于高级工具，和识别快照分别显示。人工源码可为片段或完整文档：片段使用人工模板，完整文档按照自身纸型、字体与分页。

历史布局校准保留原行、基线、公式组和画布编辑。固定来源稿统一编辑 LaTeX 源码，不提供原行校准或旧封面类型、书目信息切换；实际页面类别在识别内容面板显示。历史 / 人工稿模板设置可保存自由字体、字号、行距、缩进、段距与边距；这些设置不改动新识别的固定规则。

历史 `printed_original_only` 或 `legacy_all_visible` 任务明确显示历史范围，不自动升级为 `printed_fixed_layout`；恢复或补做继续遵守原任务范围。旧 V1 运行还使用 `expected_arrangement_revision` 并沿旧处理器恢复。旧编辑、校准、单页 / 整书编译和直接导出接口保留；旧直接导出反映当前保存稿，新识别下载使用冻结快照。

## 新 API

路径以下列 `/api/books/{book_id}` 为前缀。普通轮询只读轻量摘要，单页内容及来源按需获取。

| 方法与路径 | 内容 |
| --- | --- |
| GET `/overview` | 项目、来源文件摘要，`pages` 为空 |
| POST `/files` | 多文件导入；返回成功资料及逐项 `import_errors` |
| GET、PUT `/selection` | 选择草稿；保存 `page_ids`、`source_versions`、`expected_selection_revision` |
| GET `/source-pages?offset=0&limit=100&source_id=...` | 稳定源页列表；limit 最高 500 |
| GET `/source-pages/{page_id}/preview` | 源图；历史 / 运行结果传 `run_id` 读取冻结来源 |
| POST `/runs` | `selection_revision`、`client_request_id`、可选 `policy`、`request_limit`、`continuation_run_id`；新任务默认固定范围 |
| GET `/runs/summaries`、`/runs/{run_id}/summary` | 执行阶段、内容统计、用量、范围及各格式状态 |
| GET `/runs/{run_id}/outcomes?offset=0&limit=100` | 分页结果摘要；limit 最高 500 |
| GET `/runs/{run_id}/pages/{page_id}/content` | 该运行精确候选 `PageContent`，未取得时为 `null` |
| POST `/runs/{run_id}/pause`、`resume` | 暂停或恢复同一任务 |
| GET `/output-snapshots/{snapshot_id}` | 冻结页序、来源、内容 / 布局修订及格式状态 |
| GET `/output-snapshots/{snapshot_id}/{json\|pdf\|latex}` | 只下载已可用格式；PDF `?inline=true` 用于预览 |
| GET `/output-snapshots/{snapshot_id}/errors` | PDF / LaTeX 完整缺失页及原因 |
| GET 项目根路径、`/runs`、`/runs/{run_id}` | 高级兼容完整详情 |

新 `PageContent` 使用 `recognition_scope='printed_fixed_layout'`、`fixed_layout_version=1`；新增 `type='latex'` 内容块，其 `category` 为固定分类、`latex` 为模型正文片段。图形仍为 `type='figure'`，坐标用于资源管理，不作为正文几何排版条件。未决片段的 `region_id` 可为空；新流程无区域计划前置。旧内容类型继续保留，完整契约见 [固定排版说明](FIXED_LAYOUT_WORKFLOW.md)。

重复 `client_request_id` 返回原任务，不会重复启动。来源 / 修订冲突、竞争任务或格式未就绪返回 409；无效范围返回 422；不存在的任务、页面或快照返回 404。错误详情包含页面身份、零基位置、源文件页码、来源版本、修订及限长原因，不公开模型正文。所有任务、来源和快照需属于当前项目。

## 升级与故障处理

原有增量迁移在首次写入前保留相应数据库备份，旧备份不覆盖；已有源文件、人工稿、修订及用量保留，历史任务不会变成新范围。迁移不会调用模型；本轮未试跑迁移。

升级或换电脑前停止服务并备份项目及自定义数据目录。数据库备份可能含明文凭据。没有一键历史恢复界面；回退需保留当前数据库，在独立目录恢复与版本相符的备份。虚拟环境、前端依赖和启动器缓存在新电脑重建。

模型配置错误先核对协议、地址、模型和密钥；模型列表读取与本地配置检查不能证明真实推理能力。PDF 失败时查看错误说明，确认 XeLaTeX、模板宏包、宽公式 / 表格和图形资源；已保存分类内容仍可查看。前台连接中断时后台可能仍在运行，可重新连接读取任务状态。

启动器问题查看 `.cache/launcher/` 日志及 [旧编译环境说明](LATEX_LAYOUT.md#编译环境)。[历史修复报告](RENDERING_REPAIR_VERIFICATION.md) 与旧验收清单仅供历史参考。当前固定排版改造未测试、未运行验证。
