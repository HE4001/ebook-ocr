# 左右页与打印版

页面识别结果中的 `page_side` 表示原书页面属于左页、右页或无法确定。现有模板默认使用对称边距，打印装订版按已知页侧镜像边距。原书还原可以输出原页尺寸，或将整个源画布等比放入项目纸型；项目纸型下同样可按已知页侧移动装订留白。自定义完整文档保留自身纸型、边距与分页。该选项不修改识别结果。依赖见 [LaTeX 排版说明](LATEX_LAYOUT.md)，本轮实测见 [修复验收报告](RENDERING_REPAIR_VERIFICATION.md)。

## 页侧识别与持久化

页面代理在一次正常识别请求中返回六个兼容字段和 v2 的 `response_version`、`layout`。`page_side` 只允许 `left`、`right`、`unknown`；内容页的 `cover_fields` 为空数组，封面封底直接返回可见书目、空正文和空页眉页脚、`layout:null`，其页侧为 `unknown`。

普通内容页只根据当前图像的实质页脚判断页侧：

1. 页脚中有非空原书页码时，优先看整组页码相对整页中轴的位置。明确靠左的页码对应 `left`，明确靠右对应 `right`，不要求紧贴边缘；`· 数字 ·` 自身对称或语段内部居中不代表它位于整页中央。多个页码位置冲突、页码位于整页中央或位置不明确时，返回 `unknown`。
2. 只有没有实质页码时，才看其他非空页脚。所有实质页脚一致靠左可判 `left`，一致靠右可判 `right`；居中、两侧混合或证据冲突均为 `unknown`。
3. 没有实质页脚时返回 `unknown`。不能用页眉、页码数字的奇偶、文件名、源页号、编排顺序、相邻页或历史上下文猜测页侧。

后端收到新的模型响应后，按上述优先规则从同一次识别的 `footer_segments` 统一确定 `page_side`，避免页脚已经明确靠左或靠右，页侧字段却仍为未知或相反。居中、位置冲突、没有非空页脚的内容页及所有封面、封底统一保存 `unknown`。这个一致性检查不会重新定位图像；如果模型把页脚位置识别错了，仍需要重新识别原页。

`Page` API 结果和 JSON 导出均携带 `page_side`。数据库新增 `pages.page_side TEXT NOT NULL DEFAULT 'unknown'`；旧库增量迁移只填默认值，保留已有文本、页眉页脚、状态、用量和尝试次数，不根据旧页脚补算，也不会自动重新识别。旧结果需要主动重新识别，才会获得模型的页侧判断；重新识别仍可能得到 `unknown`。

人工保存正文会保留已有页侧；切成封面或封底时清为 `unknown`，再切回内容页也不会恢复旧页侧。没有人工编辑页侧的字段或新增模型设置。处理失败保留旧结果及旧页侧。

## 使用打印版

在整书预览的操作区开启“打印装订版”，再点击“生成/更新 PDF”或下载 LaTeX。选项默认关闭，切换项目后恢复关闭，不写入项目记录或浏览器持久化设置。装订选项也传给本页草稿 PDF；更改后已有 PDF 预览失效，需要重新更新。

原书还原的“原页尺寸”保持画布尺寸、比例与原位置，打印装订选项不另加边距。选择“项目纸型”时，按纸张可用宽高取一个统一缩放倍率，保留所有原行、公式、页眉和页脚之间的关系；不能为凑页单独缩小某行。已知左页的右侧是内侧，已知右页的左侧是内侧，未知页侧保持对称留白。

开关旁显示当前已编排页面的可用数量。项目纸型下的还原正文页只要页侧已知便可应用装订留白；原页尺寸下不另加边距。模板/自定义片段需是正文页、存在非空页脚且页侧已知；完整自定义文档使用自身边距，不计入可用数量。无可用页时开关禁用。需要页侧信息可主动重新识别，缺乏明确页脚依据仍可能为 `unknown`，应用不会自动补判或发起请求。

“居中”表示纸上的内容区域使用对称页边距，不会把正文段落设为居中文字。打印版只移动内容区域、调整装订留白；正文段落、页眉页脚语段原有的左中右对齐方式不变。

已知左页右侧为装订内侧，已知右页左侧为装订内侧。内侧边距为当前基础边距的 1.2 倍，外侧为 0.8 倍，两侧合计宽度不变。基础边距由 `Book.layout.margin_mm` 指定，留空时使用纸型默认值；下表列出默认值。模板/自定义片段的 `unknown`、无非空页脚的内容页、封面和封底保持对称边距，不凭页序补判页侧。

| 纸型 | 尺寸（mm） | 原对称边距（mm） | 打印版内侧 / 外侧（mm） |
| --- | --- | --- | --- |
| A4 | 210 × 297 | 18 | 21.6 / 14.4 |
| A5 | 148 × 210 | 14 | 16.8 / 11.2 |
| A6 | 105 × 148 | 10 | 12 / 8 |
| B5（ISO） | 176 × 250 | 16 | 19.2 / 12.8 |
| B6（ISO） | 125 × 176 | 12 | 14.4 / 9.6 |
| 6 × 9 英寸 | 152.4 × 228.6 | 14 | 16.8 / 11.2 |

模板的六种纸型继续使用各自默认字号、纸张尺寸及封面留白规则，也可在整书排版中指定字号与边距。完整文档使用自身字号和纸张设置。打印已生成 PDF 时使用 PDF 自身的纸张尺寸，避免打印机缩放覆盖页面设置。

## 跨页规则

屏幕预览展示实际编译 PDF。LaTeX 模板使用 `geometry`，按每个源页的 `page_side` 设置固定左右边距；长正文续页沿用源页版式，不按输出物理页码奇偶切换边距。完整文档的分页和边距由自身源码决定。

各源页独立编译后按编排合并，包括保留全部输出页的完整自定义文档。源页顺序不变，不插入用于凑左右面的空白页，也不强制某个源页落到实际物理左页或右页。模板/自定义片段的未知页侧、无非空页脚和封面、封底使用对称边距。

还原路径逐源页生成一张画布，实际 PDF 页数仍会检查；意外输出多张会产生异常分页诊断并不能标为通过。现有模板或自定义文档可自然续页，模板异常续页会诊断。每条 `page_map` 保存稳定源页 ID、编排位置、输出起止页、修订、策略及可用坐标变换，混合文档不能用输出页序猜源页。本项目不按物理左右面插空白页或拼版。

## 导出边界与实现入口

前端将临时 `printVersion` 通过 `print_version` 查询参数传给 `/export.tex`、整书 `/compile`、本页 `/pages/{number}/compile` 及布局草稿 `/pages/{number}/compile-layout-pdf`，默认均为 `false`。后端按源页独立编译和缓存，再按编排顺序合并；自定义完整文档保持全部输出页。源码导出单份为 `.tex`，多份为含编号 `.tex` 及编排映射的 ZIP，端点名仍为 `export.tex`。

JSON 始终导出原 API 数据，包含 `page_side`，不加入 `printVersion`；切换选项不会重新识别、改变正文、页眉页脚、页侧或用量。当前下载格式为 LaTeX、PDF 和 JSON，不再提供 Markdown 或 HTML 导出。
