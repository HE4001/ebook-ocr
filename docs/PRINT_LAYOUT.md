# 左右页与打印版

页面识别结果中的 `page_side` 表示原书页面属于左页、右页或无法确定。整书预览默认使用居中版式；勾选“打印版本”后，预览、独立 HTML 和浏览器打印采用适合装订的镜像页边距。该选项只改变输出排版，不修改识别结果。

## 页侧识别与持久化

普通页面代理的严格 JSON Schema 包含五个必填字段：`page_kind`、`page_side`、`header_segments`、`body_markdown`、`footer_segments`。`page_side` 只允许 `left`、`right`、`unknown`。独立特殊页面子代理仍只返回 `page_kind` 和 `cover_fields`，合并后的封面、封底页侧为 `unknown`。

普通内容页只根据当前图像的实质页脚判断页侧：

1. 页脚中有非空原书页码时，优先看页码位置。明确靠左的页码对应 `left`，明确靠右对应 `right`；多个页码位置冲突、页码只居中或位置不明确时，返回 `unknown`。
2. 只有没有实质页码时，才看其他非空页脚。所有实质页脚一致靠左可判 `left`，一致靠右可判 `right`；居中、两侧混合或证据冲突均为 `unknown`。
3. 没有实质页脚时返回 `unknown`。不能用页眉、页码数字的奇偶、文件名、源页号、编排顺序、相邻页或历史上下文猜测页侧。

后端对没有非空页脚的内容页及所有封面、封底统一保存 `unknown`；其他内容页保留模型给出的页侧，不再自行推断。

`Page` API 结果和 JSON 导出均携带 `page_side`。数据库新增 `pages.page_side TEXT NOT NULL DEFAULT 'unknown'`；旧库增量迁移只填默认值，保留已有文本、页眉页脚、状态、用量和尝试次数，不根据旧页脚补算，也不会自动重新识别。旧结果需要主动重新识别，才会获得模型的页侧判断；重新识别仍可能得到 `unknown`。

人工保存正文会保留已有页侧；切成封面或封底时清为 `unknown`，再切回内容页也不会恢复旧页侧。没有人工编辑页侧的字段或新增模型设置。处理失败保留旧结果及旧页侧。

## 使用打印版

在整书预览的操作区勾选“打印版本”，再下载独立 HTML 或使用“打印 / 存为 PDF”。选项默认关闭，切换项目后恢复关闭，不写入项目记录或浏览器持久化设置。单页校对继续使用默认居中预览。

“居中”表示纸上的内容区域使用对称页边距，不会把正文段落设为居中文字。打印版只移动内容区域、调整装订留白；正文段落、页眉页脚语段原有的左中右对齐方式不变。

已知左页右侧为装订内侧，已知右页左侧为装订内侧。内侧边距为所选纸型原边距的 1.2 倍，外侧为 0.8 倍，两侧合计宽度不变。`unknown`、无页脚的内容页、封面和封底保持对称边距，不凭页序补判页侧。

| 纸型 | 尺寸（mm） | 原对称边距（mm） | 打印版内侧 / 外侧（mm） |
| --- | --- | --- | --- |
| A4 | 210 × 297 | 18 | 21.6 / 14.4 |
| A5 | 148 × 210 | 14 | 16.8 / 11.2 |
| A6 | 105 × 148 | 10 | 12 / 8 |
| B5（ISO） | 176 × 250 | 16 | 19.2 / 12.8 |
| B6（ISO） | 125 × 176 | 12 | 14.4 / 9.6 |
| 6 × 9 英寸 | 152.4 × 228.6 | 14 | 16.8 / 11.2 |

六种纸型继续使用各自已有的字号、纸张尺寸及封面留白规则。打印时应在浏览器对话框选择一致的纸型，并关闭浏览器附加的页眉页脚。

## 跨页规则

屏幕预览按每个源页的 `page_side` 显示对应装订边，不模拟完整的物理纸张分页。浏览器打印使用固定命名页面 `book-left`、`book-right`、`book-centered`，按源页识别的左右位置预留装订边距；长正文续页沿用源页版式，不按物理页码奇偶切换边距。

源页之间保留普通 `break-before: page` 分页，源页顺序不变，不插入用于凑左右面的空白页，也不强制某个源页落到实际物理左页或右页。未知页侧和封面、封底使用对称的 `book-centered` 页面规则。

一个源页仍可能占用多张打印纸，复杂表格和长段落的分页由浏览器决定。该实现不精确复刻原书像素坐标，也不提供按物理页码拼版的功能；实际分页需要在打印结果中核对。

## 导出边界与实现入口

前端以临时 `printVersion` 布尔值传给 `BookContent`、`buildStandaloneHtml` 和 `paperPrintCss`，三处默认均为 `false`。独立 HTML 内嵌所选纸型和当前版式的样式，离线打开后可继续打印。

JSON 始终导出原 API 数据，包含 `page_side`，不加入 `printVersion`；切换选项不会重新识别、改变正文、页眉页脚、页侧或用量。Markdown 导出接口维持原有内容合并规则。

本轮主代理完成了定向后端检查、前端构建、六纸型版心检查及 A5 / A6 实际 PDF 检查，范围和限制见 [acceptance.md 的本轮记录](acceptance.md#本轮左右页与打印版定向验证)。该结果不代表真实模型页侧判断质量已验收。
