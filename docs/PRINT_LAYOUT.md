# 左右页与打印版

页面识别结果中的 `page_side` 表示原书页面属于左页、右页或无法确定。整书预览默认使用居中版式；开启“打印装订版”后，LaTeX 源文件与实际 PDF 采用适合装订的镜像页边距。该选项只改变输出排版，不修改识别结果。当前 PDF 由本机 XeLaTeX 编译，依赖与排版设置见 [LaTeX 排版说明](LATEX_LAYOUT.md)。

## 页侧识别与持久化

普通页面代理的严格 JSON Schema 包含五个必填字段：`page_kind`、`page_side`、`header_segments`、`body_latex`、`footer_segments`。`page_side` 只允许 `left`、`right`、`unknown`。独立特殊页面子代理仍只返回 `page_kind` 和 `cover_fields`，合并后的封面、封底页侧为 `unknown`。

普通内容页只根据当前图像的实质页脚判断页侧：

1. 页脚中有非空原书页码时，优先看整组页码相对整页中轴的位置。明确靠左的页码对应 `left`，明确靠右对应 `right`，不要求紧贴边缘；`· 数字 ·` 自身对称或语段内部居中不代表它位于整页中央。多个页码位置冲突、页码位于整页中央或位置不明确时，返回 `unknown`。
2. 只有没有实质页码时，才看其他非空页脚。所有实质页脚一致靠左可判 `left`，一致靠右可判 `right`；居中、两侧混合或证据冲突均为 `unknown`。
3. 没有实质页脚时返回 `unknown`。不能用页眉、页码数字的奇偶、文件名、源页号、编排顺序、相邻页或历史上下文猜测页侧。

后端收到新的模型响应后，按上述优先规则从同一次识别的 `footer_segments` 统一确定 `page_side`，避免页脚已经明确靠左或靠右，页侧字段却仍为未知或相反。居中、位置冲突、没有非空页脚的内容页及所有封面、封底统一保存 `unknown`。这个一致性检查不会重新定位图像；如果模型把页脚位置识别错了，仍需要重新识别原页。

`Page` API 结果和 JSON 导出均携带 `page_side`。数据库新增 `pages.page_side TEXT NOT NULL DEFAULT 'unknown'`；旧库增量迁移只填默认值，保留已有文本、页眉页脚、状态、用量和尝试次数，不根据旧页脚补算，也不会自动重新识别。旧结果需要主动重新识别，才会获得模型的页侧判断；重新识别仍可能得到 `unknown`。

人工保存正文会保留已有页侧；切成封面或封底时清为 `unknown`，再切回内容页也不会恢复旧页侧。没有人工编辑页侧的字段或新增模型设置。处理失败保留旧结果及旧页侧。

## 使用打印版

在整书预览的操作区开启“打印装订版”，再点击“生成/更新 PDF”或下载 LaTeX。选项默认关闭，切换项目后恢复关闭，不写入项目记录或浏览器持久化设置。当前装订选项也传给本页草稿 PDF；更改后已有 PDF 预览失效，需要重新更新。

开关旁显示当前已编排页面中可应用装订边距的页数。只有正文页、存在非空页脚文字且已识别为 `left` 或 `right` 的页面可应用；其他页面保持居中。如果没有可用左右页信息，开关禁用并明确提示，LaTeX 和 PDF 均保持居中。需要页侧信息时可主动重新识别对应页面；缺少明确页脚依据时，重新识别仍可能得到 `unknown`，应用不会自动补判或发起模型请求。

“居中”表示纸上的内容区域使用对称页边距，不会把正文段落设为居中文字。打印版只移动内容区域、调整装订留白；正文段落、页眉页脚语段原有的左中右对齐方式不变。

已知左页右侧为装订内侧，已知右页左侧为装订内侧。内侧边距为当前基础边距的 1.2 倍，外侧为 0.8 倍，两侧合计宽度不变。基础边距由 `Book.layout.margin_mm` 指定，留空时使用纸型默认值；下表列出默认值。`unknown`、无非空页脚的内容页、封面和封底保持对称边距，不凭页序补判页侧。

| 纸型 | 尺寸（mm） | 原对称边距（mm） | 打印版内侧 / 外侧（mm） |
| --- | --- | --- | --- |
| A4 | 210 × 297 | 18 | 21.6 / 14.4 |
| A5 | 148 × 210 | 14 | 16.8 / 11.2 |
| A6 | 105 × 148 | 10 | 12 / 8 |
| B5（ISO） | 176 × 250 | 16 | 19.2 / 12.8 |
| B6（ISO） | 125 × 176 | 12 | 14.4 / 9.6 |
| 6 × 9 英寸 | 152.4 × 228.6 | 14 | 16.8 / 11.2 |

六种纸型继续使用各自默认字号、纸张尺寸及封面留白规则，也可在整书排版中指定字号与边距。打印已生成 PDF 时使用 PDF 自身的纸张尺寸，避免打印机缩放覆盖页面设置。

## 跨页规则

屏幕预览展示实际编译 PDF。LaTeX 模板使用 `geometry`，按每个源页的 `page_side` 设置固定左右边距；长正文续页沿用源页版式，不按输出物理页码奇偶切换边距。

源页之间由 LaTeX 模板分隔，源页顺序不变，不插入用于凑左右面的空白页，也不强制某个源页落到实际物理左页或右页。未知页侧、无非空页脚和封面、封底使用对称边距。

一个源页仍可能占用多张打印纸，复杂表格和长段落的分页由 LaTeX 决定。该实现不精确复刻原书像素坐标，也不提供按物理页码拼版的功能；实际分页需要在生成的 PDF 中核对。

## 导出边界与实现入口

前端将临时 `printVersion` 通过 `print_version` 查询参数传给 `/export.tex`、整书 `/compile` 和本页 `/pages/{number}/compile`，默认均为 `false`。后端 `backend/latex_export.py` 的 `build_latex` 共用纸型和固定源页侧别规则，PDF 编译结果可离线阅读和打印。

JSON 始终导出原 API 数据，包含 `page_side`，不加入 `printVersion`；切换选项不会重新识别、改变正文、页眉页脚、页侧或用量。当前下载格式为 LaTeX、PDF 和 JSON，不再提供 Markdown 或 HTML 导出。
