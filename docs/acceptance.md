# 验收清单

本清单用于手工验收当前边界。勾选前应记录实际命令和结果；文档本身不把未执行的项目写成已验证。

## 运行与接口

- [ ] 后端能按 README 的实际命令启动，并只监听 `127.0.0.1`。
- [ ] 前端能按 README 的实际命令启动，能访问后端 `/api/health` 并显示空态。
- [ ] `GET /api/health` 返回 `{"status":"ok"}`。
- [ ] 设置页区分 API 根地址、Responses 路径和页面代理模型；读取设置不返回密钥。
- [ ] 首次打开时模型名称和密钥为空能正常显示；应用不替用户选择某个供应商或模型。
- [ ] 空白或省略密钥时保留已有密钥，非空值替换，`clear_api_key=true` 优先清除；密钥保存于默认 `backend/data/app.db` 的独立 SQLite 凭据记录中，使用本机明文存储。
- [ ] 后端重启后从 SQLite 加载已保存密钥；密钥不出现在普通设置 JSON、浏览器存储、日志或书籍导出。升级到支持持久化密钥的版本后，重启新版并重新输入保存一次旧进程 key。
- [ ] 连接测试只在用户主动操作后发生，失败信息不泄漏密钥或原始敏感响应。

## 导入与逐页处理

- [ ] PDF、PNG、JPEG 能导入并显示页数和状态。
- [ ] PDF 保留 `source.pdf`，每个 `page-XXXX.pdf` 恰好一页，并保留源页尺寸、旋转和裁切；PNG 从对应单页 PDF 渲染。
- [ ] EPUB/MOBI 被明确拒绝或提示尚未支持，没有伪装成功。
- [ ] 处理按页串行执行，每页代理只接收当前页独立上下文；状态能显示 `uploaded`、`processing`、`ready`、`failed`、`interrupted`。
- [ ] 默认“处理”只处理当前页；可手动选择多页或整本，整本范围包含已完成页。
- [ ] `POST /api/books/{id}/process` 不带请求体或省略 `pages` 时处理整本；页码列表非空、页码合法、去重并排序，同书并发返回 `409`。
- [ ] 已完成页可重复处理；覆盖前提示，成功结果替换旧文本，失败时旧文本保留；尝试次数和已知用量累计。
- [ ] 书籍在本轮所选范围处理期间保持 `processing`/`pausing`；所选页成功但仍有未处理页时回到 `uploaded` 且无错误。
- [ ] 未保存草稿不会在处理时静默丢失；暂停时当前页完成后进入 `paused`，后续按当前所选范围处理，暂停状态可跨重启保留。
- [ ] 旧 PDF 缺单页文件时，只为本次所选页面补齐。
- [ ] 重启后运行中的任务变成 `interrupted`，不会继续持有隐含后台任务。

## 页面结果与校对

- [ ] `Page` 返回 `number`、`status`、`error`、`text`、`header_segments`、`footer_segments`、`usage`、`attempts`；不要求用户编辑坐标或图片块。
- [ ] 正文文本保留原页阅读顺序、标题、列表、引用、公式、表格、图注和脚注；原书页眉、页脚及所在页码单独保留为语段。
- [ ] 页面代理请求使用 JSON Schema；页眉与页脚保存为纯文本语段，只有正文按 Markdown 保存，空白页返回空语段和空正文，手写批注不进入结果。
- [ ] 人工 PUT 只提交 `{text}`，运行中的页面拒绝修改。
- [ ] 应用内模型请求不创建 Codex 任务，也不携带其他页面聊天历史。

## 用量与导出

- [ ] `Usage` 的 token 字段缺失时保持 `null`，不估算、不显示为零。
- [ ] 自动或手动重试累计各次已知用量；拒绝、incomplete、缺少正文带有 usage 时也计入；未知消耗使 `complete=false`。
- [ ] JSON 导出包含 `book.usage`、`pages[].usage` 和 `pages[].attempts`，字段固定且能通过 [示例 JSON](../examples/sample-export.json) 解析。
- [ ] 整书预览提供 JSON、HTML 和浏览器打印；没有 Markdown 下载按钮，后端 Markdown 导出接口仍保留。
- [ ] 不宣称支持 EPUB/MOBI、后端 PDF 排版引擎、自动跨页合并、自动删页眉脚注、图表重绘或其他契约之外的能力。

## 最小验证记录

只执行与核心风险对应的少量检查：一次示例 JSON 解析、一次 PDF 两页拆分/渲染检查、一次后端健康接口检查、一次前端类型检查或构建（由对应代理负责）。不进行付费模型调用、性能压测、覆盖率测试或重复完整测试。

PDF 代理已用临时两页 PDF 验证页序、单页 PDF 页数、尺寸/旋转/裁切保留以及 PNG 尺寸与输出；临时文件未放入用户书库。该检查不代表真实模型识别质量已验证。

后端代理已报告以下三项定向 unittest 通过：usage 重试累计与解析失败计费、旧数据库含公式/表格文本及未知 usage 的迁移、API 页面文本上传/校对/导出闭环。

前端代理已完成一次 `pnpm build`，并在独立端口的内存 mock 环境检查粗体、斜体、公式、表格、页眉页脚以及未知 token 的显示。浏览器标签及测试进程已关闭，测试端口确认不再监听。未修改真实书库、设置或调用真实模型；本轮未进行真实 OCR 质量验收。

启用新版需先运行根目录 `stop.bat`，再运行 `start.bat` 并刷新页面。后端启动时执行旧数据增量迁移，不自动重新处理已完成页面；升级到持久化密钥版本后，需在新版设置中重新输入并保存一次旧进程仍在使用的 API 密钥，之后不必每次重启重填。为避免中断用户正在运行的任务，本轮没有主动重启现有服务。
