## 已交付行为

- 默认流程为文件→选页→识别，结果是识别完成状态。上传成功自动进入选页；有序稳定页面 ID 和来源版本保存为草稿；“下一步”只保存选择，“开始识别”才启动任务。
- 正常界面使用来源分页和运行摘要，高级编辑、源码、布局校准按需打开。未确认启动保留完整幂等身份；刷新和断线恢复持久任务。暂停等待已发送请求结算，继续复用已保存阶段。
- `PageContent` 是内容权威，统一文字视觉行、数学、公式编号、表格单元格及图形。响应有界正文先本地保存，再严格解析；完整 JSON 中有效块独立保留，截断 JSON 不猜补。内容无需先取得完整布局或 PDF。
- 识别前做粗区域和阅读顺序分析；普通页使用整页输入，复杂/小字区域按需带概览与原始高清裁切。复核从完整源页出发，可指出候选之外的遗漏；PDF 原生文本仅为辅助证据。
- 局部恢复从源图独立重读，不把旧答案作为标准；程序绑定旧修订、保留无关内容，独立复核确认改善且未新增问题后才采用。无改善时保留最佳候选和必要源区域；相同失败输入策略不反复发送。
- 精确布局在内容保存后派生。字体、几何、缺字、碰撞及编译问题进入布局/输出处理，不重跑整页文字识别；有限调整后可安全替代的区域保留源图，无法可靠局部替代时才保留原页。
- 输出冻结同一选择、来源、内容/布局修订与设置。内容 JSON、PDF、LaTeX/资源包分别生成和结算；原页 PDF 直接读取原 PDF/图片，不依赖完整布局、字体或 XeLaTeX。重排候选缺失则 PDF 明确失败，不静默改写页结论。
- 结果分别显示可编辑、含保留区域、仅原页、未形成结果；当前受保护旧稿另计。已处理不等于识别成功，只有原页不算文字识别，全失败显示中性/失败状态。必要错误详情保留完整缺失页列表。

## 预算、版本与保护

默认整轮共享请求额度为 `6N`，单页安全上限 `12`，每页暂时错误共享重试最多 `2` 次，局部恢复最多 `2` 轮，候选编译最多 `3` 次；默认模型并发 `2`，渲染串行。基础识别与首次复核额度按冻结页序保护，局部恢复和修后复核原子预约。

已发送失败及未知消费计数，未发送预约才可退还；同运行未知消费不自动重发。多目标恢复的暂时重试显式引用 `retry_of_attempt_id`，继承失败请求的目标块与恢复轮；同预约身份不能更换父请求，已派生重试的旧失败不能重复派发。中断后未发送子预约复用，取消重试不会误退恢复轮。用户显式续做建立关联运行和新预算，继承已取得内容。

每个请求使用独立上下文：OpenAI Responses `store:false`，不续接 `previous_response_id`；Gemini 仅当前 `contents`，不累积历史响应或思考签名。持久响应用于本地解析和诊断。

选择 CAS、启动幂等和人工稿修订保护保留。运行中新人工保存可以进行，本轮候选不会覆盖竞争修订；本轮新内容仍保留供查看和输出。修改输出设置使继承布局重新派生，内容和复核结果保留。相同输入/设置可复用已有 PDF，含新快照身份的 JSON/LaTeX 包重新生成；可选预览 PNG 或 LaTeX 资源缺失不使已生成 PDF 失效。

新增契约和字段使用现有 SQLite 表的增量迁移及写前备份 `app-before-ocr-v2.db`。旧运行保持 V1 显式分派，旧人工稿、来源、修订和历史记录保留；不将旧 `ready` 或旧布局当作 V2 内容通过。迁移代码未运行。
