# 整页识别与固定排版工作流

开始日期：2026-10-07；本次接续更新：2026-10-17。实现状态：未测试、未运行验证；当前文档替代历史设计中关于原书版面还原的默认产品要求。历史稿件、运行、测试和设计记录继续保留。

## 目标与入口

将完整源页图像直接交给识别模型，按印刷内容的类别和阅读顺序输出 LaTeX 正文片段。程序应用唯一固定模板，合理重排、自动折行、自然分页。原图是内容证据，正文不依赖原页字号、基线、分栏或原视觉行定位。

主界面为上传、选页、识别与结果。启动前展示固定规则；结果按页提供分类标签、可读 LaTeX、未决内容、冻结原图和 PDF / JSON / LaTeX 下载。手工源码编辑可主动使用，不构成审批关卡。

## 固定规则版本 1

纸型沿用启动时的项目纸型，默认 A4，可选择 A4、A5、A6、B5、B6 或 6×9 英寸。所有纸型四边固定 25 mm。正文段首缩进 2 个汉字，段间 6 pt；纸型的自由字号、行距、边距及原页画布设置不影响新流程。

| 分类 | 字号 / 行距（pt） | 前 / 后间距（pt） | 样式 |
| --- | --- | --- | --- |
| `title` 标题 | 20 / 30 | 18 / 12 | 居中、粗体 |
| `heading` 一级标题 | 16 / 24 | 12 / 8 | 左对齐、粗体 |
| `subheading` 二级标题 | 13 / 19.5 | 10 / 6 | 左对齐、粗体 |
| `paragraph` 正文 | 11 / 16.5 | 0 / 6 | 首行 2 字 |
| `equation` 公式 | 11 / 16.5 | 6 / 6 | 完整显示数学环境，保留原编号 |
| `table` 表格 | 11 / 16.5 | 6 / 6 | 完整表格环境，保留表头、数据与合并关系 |
| `list` 列表 | 11 / 16.5 | 0 / 6 | 完整列表环境，保留原标签 |
| `caption` 图表注 | 9 / 13.5 | 3 / 6 | 左对齐、原印刷文字 |
| `footnote` 脚注 | 9 / 13.5 | 3 / 6 | 左对齐、保留原标号 |
| `header` / `footer` / `page_number` | 9 / 13.5 | 3 / 6 | 居中，在阅读顺序内保留原页文字 |
| `code` 代码 | 10 / 15 | 3 / 6 | 等宽、保留有意义的代码换行 |
| `quote` 引用 | 11 / 16.5 | 3 / 6 | 正文大小，可用引用环境 |

普通正文按语义段落成块，程序允许重新折行和自然分页。标题不使用模型生成的章节命令；程序在标题前用 `Needspace` 预留标题间距、一行标题和两行正文的空间，减少标题孤立在页底的情况。页码作为可识别内容保留，不生成新的原书页码。

公式片段已经包含完整显示环境，程序不重复套定界符；长公式可在原有关系或运算符处使用 `aligned / multline*` 等环境换行，保留原字符、数学关系和编号，不缩放或缩字。表格也不重复套环境；短表优先使用 `tabularx{\linewidth}` 的 `X` 列，长表使用 `longtable` 及相对 `\linewidth` 的 `p` 列，单元格文字可自动换行。列宽总和为单元格间距和竖线留出空间，不沿用原书绝对列宽，不缩字、缩放、删列或删数据；仍无法自然排下时保留未决说明。图表不使用浮动环境，按内容阅读位置放置。

固定模板加载 `longtable / array / tabularx / booktabs / multirow / enumitem / bm / needspace`，并以 `normalem` 选项加载 `ulem`。

固定模型片段不得包含导言区、完整文档、字号、边距、定位、分页、宏定义、读写、执行命令或任意资源路径。程序拥有模板、分类样式包裹器与图形资源映射。人工完整文档是单独的编辑入口。

## 内容契约

`RecognitionScope` 新增 `printed_fixed_layout`；`printed_original_only` 和 `legacy_all_visible` 保留为历史范围。新 `PageContent` 为：

- `schema_version=2`，`recognition_scope='printed_fixed_layout'`，`fixed_layout_version=1`。
- `blocks` 按阅读顺序排列；新文字分支为 `type='latex'`、`category`、`latex`，继承块 ID、可空 bbox、修订、响应、复核及未决信息。新块不含视觉行数组。
- `type='figure'` 继续表示图形及其真实 bbox、可见特征说明，图注另为 `caption` 块。程序裁切并管理资源，模型不返回文件路径。
- 封面、封底、目录、正文和空白使用相同契约，页面类型由 `page_kind` 表示。
- `unresolved_spans` 保存遮挡或无法辨认片段，`region_id` 可为空；整页识别不要求事先存在区域计划。
- 旧 `text / equation / table` 块继续供历史修订读取，新结果视图分别处理类型，不能把新块直接 stringify 成正文。

模型返回的 LaTeX 本身是可编辑内容，不再经过文字到 LaTeX 的二次转换。内容先保存；后续 PDF 或资源包失败不会抹掉识别内容。图形坐标用于资源定位及内容核对，不要求正文几何匹配。

固定来源的当前页使用 `render_strategy='custom_latex'` 和程序生成的完整文档，`layout_source` 为空。派生 `PageLayout` 可保存最小来源与图资源信息，几何为空，布局结论为 `approximate`，表示固定重排。

`Page` 与 `Revision` 的 `recognition_scope`、`fixed_layout_version` 为只读来源标识。当前人工源码实际修改后继续保留来源标识，`manual_protected` 明确其为人工稿；修改后的自由源码不冒充已自动复核的原 `PageContent`。当前采用稿与运行候选、快照各自保存。

## 自动阶段与输出

阶段沿用 `prepare → recognize → review → recover（按需）→ layout → render → export`：准备整页图像；直接识别及分类 LaTeX；独立核对完整源页的内容和遗漏；有界恢复；固定规则与合格图资源准备；生成固定 PDF；冻结下载文件。

首次模型请求不先做 region-plan。复核从源页出发，不能只检查已有块，也不能把合法 JSON、模型信心或编译成功当作内容完整。有明确问题和额度时，恢复重新读取整页并复核候选，不按原图坐标局部修补正文。每页重读恢复轮数是安全上限，当前同一整页重读策略仅尝试一次。每次模型请求独立构造上下文，预算预约、已发送未知消费、暂停结算和修订保护继续适用。默认额度与暂停规则见 [操作说明](usage.md#自动处理与暂停)。

只处理原书印刷内容，排除后加手写批注。未决内容保存理由；未核验的整页或混合图像不能作为新印刷输出回退。图形资源经独立核验，确认干净后才加入成品；资源不可用时保留占位和原因，不编造数据。记录图形 bbox 不代表图形资源已经形成。

同一 `OutputSnapshot` 冻结页序、来源版本、候选修订、设置和规则。JSON、PDF、LaTeX 各自保存 `pending / generating / available / failed`。LaTeX 包包含固定模板及全部引用资源；PDF 逐源页固定排版，再按选择顺序合并，单张源页可自然跨多个输出页，原页数与输出页数可以不同。下载只读取冻结资产。

## 历史与编辑边界

旧运行恢复或补做沿用原冻结范围，固定任务补做沿用原冻结纸型和输出设置，历史产物不被改标为固定排版。新建任务才进入新默认范围。旧 `source_fidelity`、`legacy_template`、原行校准、直接导出等继续作为历史兼容工具；UI 明确标识历史范围与当前固定结果。

固定来源稿的高级编辑统一提供自由源码，隐藏原行校准及旧封面类型、书目信息控件；实际页面类别在识别内容面板显示。模板自由字号和边距只用于历史 / 人工稿，固定新任务的后端使用固定常量，不只依靠界面文案约束。完整人工源码按自身纸型和分页执行，改稿不改变原识别快照。

旧设计文档中关于视觉行、几何派生和原书版式还原的默认要求不再定义本轮新流程。旧迁移备份、源文件、人工稿和历史修订继续保留，不据旧 `ready` 或旧报告声称当前识别通过。
