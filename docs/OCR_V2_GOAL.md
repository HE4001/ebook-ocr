目标：用户选择文件后自动进入选页界面，完成选页后进入识别页，点击一次开始识别即可全自动完成内容识别、独立内容复核、有界恢复、版面还原及结果生成。前端简洁，明确显示现在在做什么、已处理多少页、取得哪些可用结果；不让用户逐页校对、处理疑点或填写坐标。不针对某一页、某本书或样本特化。

必须实现优化后的识别过程，而非仅重新安排界面和调用顺序：

2. 清晰普通页保持整页识别；小字、密集内容、复杂公式/表格按需采用原始分辨率局部图，并提供本页概览及必要周边。按内容边界裁切，保留坐标映射，不能机械切碎公式/表格；重叠结果按来源位置及内容对应合并，不能仅凭文本相同删除真实重复内容。
3. 文字、公式、表格、图形按各自职责使用精简输出契约，页眉页脚单独保留角色；沿用已配置模型和协议，不建立多模型投票平台。以内容块为最小保存/恢复单位，一个块失败不能清空整页，整段响应截断不能靠猜补解析伪造完整内容。
4. 自动复核同时覆盖从完整源页出发的遗漏检查与对应块内容核对，必须能发现候选清单之外的内容；局部疑点先根据源图独立重读，再与旧修订比较和复核，不把旧错误当标准答案。墨迹信号、模型自信或两次结果一致都不能单独证明正确。
5. 原生 PDF 的文字、位置和字体作为辅助证据，扫描页以图像为主，混合页按区域处理；存在文字层不能直接跳过视觉覆盖判断。不得删除原页眉脚注或根据历史正文补写当前页。

7. 预算采用统一 policy 的整轮硬上限和按需分配，不把算法固定为每页六次调用。默认整轮最多6N次物理请求、单页安全上限12次且受整轮余额约束、每页暂时重试最多2次、每页局部恢复最多2轮；先保留其他页面基础识别/复核额度，再分配复杂处理，内容修复与修后复核一起预约。所有调用和未知消费均计数，无改善不重复同一方案，不自动加额度。详见流程规格§5.2。
