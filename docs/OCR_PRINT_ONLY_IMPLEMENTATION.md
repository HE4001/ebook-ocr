# 印刷原文本轮实现与限制

日期：2026-10-07。状态：主代理已接受本轮源码静态审查结果；未测试、未运行验证。

用户范围：只输出原书印刷内容，不保留后加手写批注；遮挡处不能补猜。

## 模块分工

- 契约与模型接入：内容来源层、区域身份、候选和采用契约、印刷范围提示及按区域核验。
- 工作流与保存：范围冻结、区域计划、恢复目标、候选替换、内容状态、快照和内部原始证据。
- 布局、成品与前端：几何匹配状态、成品源图门禁、独立正文源码、部分内容展示及本文档。

分工不构成验收结论，最终行为仍须后续验证。

## 批次、恢复与证据保存

初始印刷识别中，普通文字和公式每批最多三个完整区域；表格和 mixed 区域独立成批，unknown 区域不进入转录队列，保留归属未决。每次 operation 冻结目标区域和观察裁切，暂停恢复沿用已冻结目标；已完成批次逐批保存，后续批次失败不抹掉先前采用正文。核验可以记录原计划之外的新印刷遗漏，但不直接把复核文本追加为采用正文。

修复候选及其核验、退回差异继续作为证据保存，同一区域采用稿只引用活动候选。继续处理继承原区域计划、候选与采用记录、核验证据、覆盖观察及未决项，不以新轮初始化把它们重置。以上是当前源码的静态实现说明，尚未运行确认；真正识别效果和恢复行为仍待验证。

## 布局与成品的实现

PageLayout 和 SourceFidelityLayout 保存 recognition_scope；历史缺省 legacy_all_visible。源资源带 source_layer 和 cleanliness_verified，新印刷范围只允许 purpose=figure、printed 且明确核验干净的裁切。混合/未知来源、表格原区域和整页回退不进入新范围成品。原始证据仍由保存模块保留。

公式框内发现墨迹不能证明公式身份。新印刷范围尚无可信公式组件匹配器，因此公式定位明确 unknown；正文不因定位失败消失。历史全可见范围保留既有公式测量路径。文字位置测量仍是几何证据，不能代替文字核验。

输出适配器也对未支持数学环境的公式保留未知位置，避免其内部文字渲染类型绕过公式门禁。忠实输出与可编辑正文共用未决说明归账，区域遗漏、unknown 归属和未完成覆盖核验都会阻止忠实格式被当作完整原版。

忠实 PDF 保持既有单页几何和测量契约。未知公式定位、未知图形/表格几何或未决印刷片段会让忠实格式失败，不以源图掩盖失败。JSON 独立保存已采用正文和未决项。快照资源包另提供可编辑正文 LaTeX：采用项目纸型，保留数学结构、编号及未决说明，单元格按阅读顺序列出；这是近似重排源码，不承诺忠实版式或编译成功。明确干净的图形按对应正文图形块插入源码并打包；未知图形保留可见占位，不插入原图。区域完全遗漏、unknown 归属、未完成覆盖归账及未解决内容问题也以未决说明进入正文源码和 JSON。

快照与旧高级导出的原页回退受范围门禁；新范围不打包旧 best-candidates 自由源码。模板或自定义源码入口遇到印刷范围布局不会绕过资源门禁。生成器版本变更避免复用旧产物缓存。

无 run_id 的高级导出若冻结清单为印刷范围，要求所有页面均有同范围的布局来源；混入历史范围或缺失范围的页面时整体拒绝，并提示重新识别对应选页。检查发生在缓存读取和任何格式生成之前，避免旧页面的批注通过缓存 PDF、JSON 或源码包进入印刷成品。纯历史范围维持原导出行为；运行快照另沿用已冻结的同范围内容修订。

前端仍一次启动，说明印刷范围；显示部分内容、遮挡未决、遗漏区域、unknown 归属和覆盖归账状态，独立显示布局及文件状态。原页预览是内部对照，不计为成品成功。历史结果保留旧范围说明。

## 静态退回记录

主代理退回首次近似重排路径：移除 ampersand 会破坏数学结构，且它与单页 fidelity 编译元数据不一致。已撤回该 PDF 重排路径，改为独立可编辑正文源码，忠实 PDF 保持原契约。主代理还要求保留旧公式定位路径和去掉客户端多余 scope 字段；已按此调整。

第二轮静态退回要求细分独立数学环境与内部数学体、保留公式编号、按正文位置引用已核验图形、补充完全遗漏区域及 unknown 的可见说明，并冻结无 run_id 高级导出的实际范围。输出层已按上述要求调整；工作流模块同步高级导出范围。

续修静态检查补齐了未决说明传入忠实输出的接口；独立数学环境使用不自动编号的对应环境，原书编号单独保留，避免重排源码产生新增编号。此调整只依据源码阅读，未运行或编译。

其余退回项已在本轮修复：

- 初始空内容契约允许保存印刷区域计划与未决状态，不把尚未完成转录的空块列表当作结构错误或成功空白页。
- 继续处理继承区域计划、候选采用、核验及覆盖证据，避免初始化重置已保存成果；逐批采用后保留先前区域，候选退回证据也独立保存。
- 空白结论仍需覆盖复核；复核发现印刷区域后不能继续以空白掩盖遗漏。
- parse 问题绑定实际目标区域，避免无区域归属的问题绕过局部核验；恢复任务使用冻结目标，旧 operation 的兼容处理保留既有任务身份。
- 新范围的公式未知位置不因内部文字渲染类型而绕过门禁，模型不能自行声称可信 matched；忠实输出收到完整未决说明，PDF 失败与正文保存分别结算。
- 高级混合导出在缓存和格式生成前整体拒绝历史或范围未知页面，堵住旧缓存 PDF、JSON 页面正文和源码资源包带回批注的路径。新范围布局原因也不再声称已保留被门禁清除的源图。
