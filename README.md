# 纸页重排 · 电子书 OCR

将 PDF、PNG、JPEG 按 **上传 / 选页 → 整页图像识别与内容分类 → 分类 LaTeX → 独立复核与固定排版输出** 整理为可编辑文档。整页图像直接交给识别模型，按阅读顺序提取印刷内容；程序用统一规则重新折行与分页。新流程不要求预先还原原书布局或逐页人工审批。

这是 Windows 优先的本地单用户应用，由 Python / FastAPI 后端和 React / TypeScript 前端组成。模型服务可选 OpenAI Responses 或 Google Gemini 原生 API，由用户配置地址、模型和密钥。当前源码版本为 `0.1.0`。

本轮固定排版改造 **未测试、未运行验证**。没有运行测试、构建、类型检查、lint、试编译、应用、模型请求或迁移；历史测试和运行报告不能证明本轮有效。

## 固定排版规则

新识别范围为 `printed_fixed_layout`，固定规则版本为 `1`。选择纸型后，其他正文样式统一由程序应用：

| 内容 | 排版 |
| --- | --- |
| 纸张 | 项目纸型，默认 A4；四边 25 mm |
| 正文 | 11 pt / 16.5 pt 行距；段首缩进 2 字，段间 6 pt |
| 标题 | 20 pt 居中粗体；一级标题 16 pt、二级标题 13 pt 粗体 |
| 公式、表格、列表、引用 | 正文大小；保留原内容、结构、标签和公式编号 |
| 图注、脚注、原页页眉页脚与页码 | 9 pt / 13.5 pt 行距；页边文字按阅读顺序居中保留 |
| 代码 | 10 pt 等宽 / 15 pt 行距 |

逐源页自动折行、自然分页，再按选择顺序合并；单张源页可排成多个输出页。图表按内容顺序放置，图形资源经独立核验后由程序管理；资源不可用时保留占位和原因。只识别原书印刷内容，排除后加手写批注；遮挡、无法辨认的片段有明确未决说明。自由字号、边距、行距及原页画布设置不影响新识别的固定规则。完整规则和契约见 [固定排版工作流](docs/FIXED_LAYOUT_WORKFLOW.md)。

## 主要功能

- 多文件导入后进入选页，可按源文件或源页范围选择并保存页序；上传和选页不调用模型。部分导入失败时成功文件保留。
- 模型直接从整页图像输出按类别排列的 LaTeX 正文片段；内容先保存，PDF 或资源包失败不抹掉已有内容。
- 独立复核完整源页的内容和遗漏，有额度时整页重读恢复；首次识别不先请求区域计划。正常页一次识别加一次复核。
- 识别页在启动前展示固定规则，结果页显示内容分类、可读 LaTeX 源码、原图入口和冻结 PDF 预览。
- 每次识别、复核、恢复和重试使用独立上下文；任务冻结页序、来源版本、模型、纸型和规则。暂停等待已发送请求结算，恢复沿用原任务。
- N 页默认共享请求额度 `6N`，每页安全上限 `12`，暂时错误重试最多 `2` 次、重读恢复安全上限默认 `2` 轮、候选编译最多 `3` 次；当前同一整页重读策略仅尝试一次。失败和结果未知的已发送请求也计数。
- 默认模型并发为 `2`、渲染并发为 `1`；已有人工稿受到保护，后台候选不能覆盖运行中新保存的修订。
- 自动冻结同一输出快照，分别提供内容 JSON、固定排版 PDF 和 LaTeX / 资源包，格式状态与错误独立保存。
- 可主动编辑人工 LaTeX 稿、预览当前稿；历史原书布局和旧稿继续保留，历史任务按原流程恢复。

## 快速开始（Windows）

| 环境 | 要求 |
| --- | --- |
| Python | 3.11 或以上，包含 venv / pip |
| Node.js | 20.19+（20.x）或 22.12+；前端测试建议 22.18+ |
| pnpm | 使用 `frontend/pnpm-lock.yaml` |
| XeLaTeX | PDF 生成需要；一键启动复用本机编译器，缺失时准备 TinyTeX 与模板依赖 |
| 模型服务 | 接收图片并支持结构化输出的 Responses 或 Gemini 模型及 API Key |

1. 将源码放在本机目录，双击 `ocr.bat`，回车启动。
2. 在模型设置中保存协议、API 地址、模型和密钥。
3. 新建项目并上传 PDF / 图片，选页并保存。
4. 在识别页查看固定规则，点击“开始识别”。
5. 查看分类 LaTeX、未决内容及原图对照，下载同一快照的可用格式。

默认数据保存在 `backend/data/`；可用 `EBOOK_OCR_DATA_DIR` 指定其他本地目录。服务只监听 `127.0.0.1:8000` 与 `127.0.0.1:5173`，启动器日志在 `.cache/launcher/`。关闭菜单窗口后服务继续运行；停止或重启可能中断任务。

```powershell
.\ocr.bat Start
.\ocr.bat Start -NoBrowser
.\ocr.bat Status
.\ocr.bat Stop
.\ocr.bat Restart
```

启动器按依赖文件变化与组件缺失情况准备项目 `.venv` 和前端依赖。LaTeX 优先读取有效的 `EBOOK_OCR_XELATEX`，再查 PATH 与常规 TinyTeX 目录；缺失时准备编译器、Fandol 字体和模板宏包。Python、Node.js 和 pnpm 需预先安装。直接启动后端只查找编译器，不安装依赖；缺少编译器时 PDF 明确失败，已保存内容和可形成的 JSON / LaTeX 仍保留。

上述命令是使用说明，本轮没有执行。接入、编译和故障处理详见 [操作说明](docs/usage.md)。

## 手动启动

在项目根目录启动后端：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r backend\requirements.txt
.\.venv\Scripts\python.exe -m uvicorn backend.main:app --host 127.0.0.1 --port 8000
```

另开终端启动前端：

```powershell
cd frontend
pnpm install --frozen-lockfile
pnpm run dev
```

仓库提供本地 Vite 入口，不提供独立 EXE。当前没有实测准确率、通过率或速度结论。

## 数据、人工稿与历史任务

原文件、源页、识别响应、修订、用量和快照保存在本地。密钥以明文存入数据库的独立凭据记录；项目和数据库备份可能包含密钥及个人书籍，不要公开完整备份。

已有项目和运行不会自动改成固定排版结果。`printed_original_only` 表示此前的印刷原文流程，`legacy_all_visible` 表示历史全可见内容范围。恢复或补做旧任务继续遵循其冻结范围；新建识别才使用 `printed_fixed_layout`。旧 `ready`、满进度或可下载 PDF 不等于已通过新流程。

当前采用稿与本轮候选分别保存。高级编辑修改固定生成稿后，保存为人工源码；识别来源标识只表示出处，不保证人工修改继续符合固定规则。原识别快照可继续查看和下载。原行、基线与画布校准属于历史布局工具。

旧迁移的写前备份包括 `app-before-latex.db`、`app-before-layout.db`、`app-before-workflow.db` 和 `app-before-ocr-v2.db`；已有备份不覆盖。迁移保留源文件、历史稿件及修订，不调用模型。本轮没有试跑迁移。升级或换电脑前停止服务并备份项目和自定义数据目录；旧电脑的虚拟环境、前端依赖和启动器缓存需在新机器重建。

## 当前限制

仅支持 PDF、PNG、JPEG，每文件上限 100 MB；不支持 EPUB / MOBI 原生导入。识别质量取决于模型与原图，自动复核及有限恢复不能保证准确。未决片段和不可用图形有具体说明；印刷范围内不使用未经核验的整页或混合图像回退冒充完成。宽公式、复杂表格或资源缺失可能令 PDF 失败，已有分类内容仍单独提供。

本轮仅实现并静态阅读，**未测试、未运行验证**。仓库现有测试、验收清单及历史编译记录不能证明当前版本的运行效果。此应用按本地单用户用途提供，不包含账户、多用户权限或公网服务配置。

仓库未指定开源许可证。发布源码时避免打包运行数据、凭据和完整备份，具体步骤见发布说明。
